## 📌 Project Overview
Modern digital enterprises collect high volumes of unstructured feedback across multiple customer touchpoints—including app store reviews, ecommerce platforms, and social media channels. Traditional analytics rely on aggregated ratings (e.g., CSAT/NPS averages), which fail to expose underlying root causes, operational bottlenecks, or emerging dissatisfaction trends.

This platform bridges empirical statistical analysis with modern transformer NLP, predictive machine learning, and time-series forecasting. Built on a unified dataset of **33,643 customer interactions** from **Amazon, Google Play Store, and Twitter**, the pipeline automatically categorizes complaints, evaluates pain-point severity, predicts customer churn risk, and generates actionable executive decision reports.

## 🔬 Academic Research Questions
To align with German Master's research standards, this project addresses four core empirical questions:
- **RQ1:** *Can machine learning classification architectures outperform traditional rule-based models in evaluating multi-channel feedback?*
- **RQ2:** *To what extent can unstructured text features and pain-point severity predict customer churn risk?*
- **RQ3:** *How accurately can time-series regression models forecast future customer complaint volume trends?*
- **RQ4:** *How effectively can automated insight-extraction engines support enterprise business decision-making?*
